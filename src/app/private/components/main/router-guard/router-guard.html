Router Guards

Angular 22 | Control navigation and protect application routes

What are Router Guards?

Router Guards are functions that control whether a user can navigate to, leave, or access a particular route in an Angular application.

Types of Router Guards
Guard Purpose Use Case
CanActivate Controls access to a route. Protect Dashboard.
CanActivateChild Controls access to child routes. Protect Admin routes.
CanDeactivate Controls whether a user can leave a route. Prevent leaving an unsaved form.
CanMatch Controls whether a route matches the URL. Role-based route matching.
CanLoad Legacy lazy-loading protection. Deprecated. Prefer CanMatch.
Angular 22: Functional guards are recommended. CanLoad is deprecated. Prefer CanMatch for modern route matching and lazy-loading control.
1. CanActivate

Checks whether a user is allowed to enter a particular route. 

export const authGuard: CanActivateFn = () => {
     const auth = inject(AuthService);
     const router = inject(Router);

     return auth.isLoggedIn()
          ? true
          : router.createUrlTree(['/login']);
};

Example: Only authenticated users can access the Dashboard.

2. CanActivateChild

Checks whether a user can access the child routes of a parent route. 

export const childGuard: CanActivateChildFn = () => {
     return inject(AuthService).isLoggedIn();
};

Example: Protect all routes under the Admin section.

3. CanDeactivate

Checks whether a user can leave the current route. 

export const unsavedGuard: CanDeactivateFn<EditFormComponent> =
     (component) => {
          return component.hasUnsavedChanges()
               ? confirm('You have unsaved changes. Leave this page?')
               : true;
     };

Example: Show confirmation before leaving an unsaved form.

4. CanMatch

Decides whether a route should match the current URL. If it returns false, Angular can try another matching route. 

export const roleGuard: CanMatchFn = () => {
     return inject(AuthService).hasAdminRole();
};

Example: Match the Admin route only for users with the Admin role.

5. CanLoad (Deprecated)

Previously used to prevent lazy-loaded modules from loading when a guard returned false.

Legacy Guard

Use CanMatch instead in modern Angular applications.

Important Points
  • Angular recommends functional guards over class-based guards.
  • Guards can return boolean, UrlTree, RedirectCommand or asynchronous results.
  • Guards can return Observable or Promise values.
  • Client-side guards are not security boundaries. Always validate authorization on the backend.
