Control Flow

Conditional Rendering and Iteration in Angular

What is Control Flow?

Control Flow allows us to control how and when HTML elements are displayed based on conditions and collections.

@if @else @else if @for @empty @switch @case @default
01. @if and @else
Conditional Rendering

Used to display HTML elements when a condition is true or false.

Example 1: Show / Hide Div
@if (isDivVisible) {
Hello World! Div is visible.
}
Example 2: Offer Code
@if (isOfferCodeAvailable) { } @else {

No offer code available.

}
Example 3: Order Status
@if (orderStatus === 'new') {
Order Received
} @else if (orderStatus === 'placed') {
Order Placed
} @else if (orderStatus === 'delivered') {
Order Delivered
} @else {
Order Cancelled
}
02. @for and @empty
Looping through collections

Used to iterate over an array. The empty block displays content when the array contains no items.

City List
@for (city of cityList; track city; let i = $index) {
City {{ i + 1 }}
{{ city }}
} @empty {
No cities available.
}
03. @switch, @case and @default
Multiple Condition Matching

Used to match an expression against multiple values. @case defines matching values, while @default executes when no case matches.

@switch (paymentStatus) { @case ('pending') {
Payment is Pending.
} @case ('success') {
Payment Successful!
} @case ('failed') {
Payment Failed.
} @case ('refunded') {
Payment Refunded.
} @default {
Unknown Payment Status.
} }
Interview Quick Notes
Syntax Purpose
@if Conditional rendering
@else Alternative condition
@else if Multiple conditions
@for Iterate over collections
@empty Display when collection is empty
@switch Match multiple values
@case Define matching values
@default Fallback condition
