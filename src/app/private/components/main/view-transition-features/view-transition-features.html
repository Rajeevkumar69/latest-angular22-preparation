Angular Animations & View Transitions

Angular provides modern CSS-based animation APIs to animate elements entering or leaving the DOM. View Transitions create smooth visual transitions when navigating between different routes.
1. Modern Animation APIs

Angular provides two APIs to handle animations when elements are added to or removed from the DOM.

animate.enter

Runs an animation when an element enters the DOM. It is useful for displaying messages, dropdowns and dynamically added elements.

animate.leave

Runs an animation before an element is removed from the DOM. Angular waits for the leave animation to complete before removing the element.

Remember: animate.enter handles DOM entry, while animate.leave handles DOM removal.
2. CSS Animations

CSS animations define how an element changes its appearance over time. Angular allows us to apply these animations using CSS classes.

Important CSS Properties

  • opacity: Controls the visibility of an element.
  • transform: Changes the position or appearance of an element.
  • animation: Defines the animation name, duration and timing function.
  • @keyframes: Defines the different stages of an animation.

Note: Global CSS animations can be defined once in styles.css and reused across multiple components.

3. View Transitions
View Transitions create smooth visual transitions between the old and new page when navigating between Angular routes.

withViewTransitions()

Angular Router provides withViewTransitions() to integrate the browser's native View Transitions API with route navigation.

Customizing View Transitions

We can customize page transitions using CSS pseudo-elements:

  • ::view-transition-old(root) – Targets the previous page view and applies the exit animation.
  • ::view-transition-new(root) – Targets the new page view and applies the entry animation.

For example, we can apply fade-out and fade-in animations with translateY() to create smooth page transitions.

4. Important Points
  • Global CSS animations can be reused across multiple components.
  • animate.enter and animate.leave handle individual DOM element animations.
  • withViewTransitions() enables transitions during Angular route navigation.
  • View Transitions depend on browser support. Unsupported browsers perform normal navigation.
  • Angular Router's View Transition integration is described as developer preview in the tutorial.
  • Older Angular animation APIs are deprecated starting from Angular 20.2.
5. When to Use?
API Use Case
animate.enter Displaying messages and dynamic elements.
animate.leave Animating elements before DOM removal.
View Transitions Smooth navigation between pages and routes.
Quick Summary

animate.enter: Element enters DOM.

animate.leave: Element leaves DOM.

View Transitions: Smooth transitions between pages.
