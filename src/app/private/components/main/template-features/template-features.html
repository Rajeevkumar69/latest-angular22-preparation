Template Features

Learn how to display data, handle events and access HTML elements in Angular.

01
Template Expressions

Used to display values and perform calculations directly in HTML.

Title
{{title}}
Total Amount

{{amount * quantity | currency:'INR'}}

Comparison Result
{{amount > quantity}}
Arithmetic Operators

Used to perform mathematical calculations.

+   -   *   /   %

Example: {{amount * quantity}}

Comparison Operators

Used to compare two values and return true or false.

==   ===   !=   !==   >=   <=< /div>

Example: {{amount > quantity}}

Ternary Operator

Used to check a condition and return one of two values.

{{amount > 100 ? 'Expensive' : 'Not Expensive'}}

Nullish Coalescing Operator (??)

Returns a default value when the original value is null or undefined.

{{undefinedValue ?? 0}}

02
$event Object

Used to get event details when a user interacts with an element.

Click Event

Executes a function when the button is clicked.

Input Event

Gets the input value whenever the user types.

Value: {{inputValue}}

Keyup Event

Executes a function when a keyboard key is released.

Last Key: {{lastKey}}

Enter Key Event

Executes a function when the Enter key is pressed.

{{searchMessage}}

Escape Key Event

Clears the input when the Escape key is pressed.

03
Template Reference Variables (#)

Used to access HTML elements, components and directives directly from the template.

Access Input Value

Use a reference variable to get the input value.

{{displayName}}

ViewChild

Used to access a template element inside the TypeScript file.

Child Component

Used to access public methods and properties of a child component.

04
ng-template

Defines an HTML template that is not displayed until Angular is instructed to render it.
