Angular Zone.js & Zoneless Change Detection

Understanding how Angular detects changes with and without Zone.js.

What is Zone.js?

Zone.js is a library that helps Angular track asynchronous operations in an application and trigger change detection when those operations complete.

Zoneless Change Detection
01

Angular does not require Zone.js.

02

Angular relies on explicit notifications from its APIs.

03

These notifications tell Angular when the UI may need updating.

04

Angular schedules change detection based on these notifications.

Advantages of Zoneless
Improved Performance

Can reduce unnecessary change detection scheduling.

Smaller Bundle Size

Removing the Zone.js dependency can reduce JavaScript bundle size.

Better Debugging

Makes stack traces easier to understand.

Better Compatibility

Reduces dependency on patched browser APIs and improves integration with other libraries.

Key Takeaway

Zone-based Angular uses Zone.js to detect asynchronous operations, whereas Zoneless Angular uses explicit notifications to schedule change detection when the UI needs updating.
