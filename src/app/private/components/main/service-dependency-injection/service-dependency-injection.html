Services & Dependency Injection

Understand how Angular manages shared logic, data and dependencies across components.

01
Angular Service

A Service is a reusable class that contains shared data, business logic or functionality that can be used by multiple components.

Example

ProductService, AuthService, UserService and ApiService.

02
Dependency Injection (DI)

Dependency Injection is a design pattern where Angular provides the required dependencies to a component or service instead of creating them manually.

Example

inject(ProductService) or constructor injection.
