Angular Pipes

Angular Pipes transform and format data directly in templates, making values easier to read and display without modifying the original data.

What is a Pipe?

A pipe is a feature used to transform data in an Angular template.

Why use Pipes?

Pipes transform data for display without changing the original value.

How do Pipes work?

A pipe takes data as input, transforms it, and returns the transformed value for display.

What is a Pure Pipe?

A pure pipe runs when Angular detect a relevant changes in it's input.

What is Impure Pipe?

A Impure pipe runs more frequently & may affect application performance.

Text Transformation Pipes
3 Examples

Convert text into uppercase, lowercase, or title case.

Uppercase Pipe

Converts text into capital letters.

{{ title() | uppercase }}
Output

{{ title() | uppercase }}

Lowercase Pipe

Converts text into small letters.

{{ title() | lowercase }}
Output

{{ title() | lowercase }}

Titlecase Pipe

Capitalizes the first letter of each word.

{{ title() | titlecase }}
Output

{{ title() | titlecase }}

Async Pipe
Observable / Promise

Async Pipe subscribes to an Observable or Promise and provides its latest value to the template. It automatically unsubscribes when the component is destroyed.

Code Example
@for (user of users | async; track user.id) {
     <p> {{user.title}} </p>
}
Output @for (user of users | async; track user.id) {

{{ user.title }}

}

Formats a numeric value as currency.

{{amount() | currency:'INR' }}
Output
{{ amount() | currency:'INR' }}

Extracts a portion of a string or array.

Output
{{ userName() | slice:0: 5 }}
i18nPlural Pipe

Displays different messages depending on a numeric value.

{{
     items() | i18nPlural:{
          '=0' : 'No Items',
          '=1' : 'One Items',
          'other' : '# Items'
     }
}}
Output
{{ items() | i18nPlural:{ '=0' : 'No Items', '=1' : 'One Items', 'other' : '# Items' } }}
i18nSelect Pipe

Selects a string based on a matching key.

{{
     gender() | i18nSelect:{
          'male' : 'He',
          'female' : 'She',
          'other' : 'They'
     }
}}
Output
{{ gender() | i18nSelect:{ 'male' : 'He', 'female' : 'She', 'other' : 'They' } }}
JSON Pipe

Converts an object or value into a JSON string for debugging. 

{{userData() | json}}
Output 
{{ userData() | json }}
KeyValue Pipe

Iterates over the key-value pairs of an object or Map.

@for (user of users | keyvalue ; track user.key) {
     <p> {{user.key}} : {{user.value}} </p>
}
Output @for (user of users | keyvalue ; track user.key) {

{{user.key}} : {{user.value}}

}

Important Note

Angular pipes are pure by default. They execute when their input value or input references change. Use AsyncPipe for automatic subscription management and consider a custom pipe when you need reusable data transformation logic.
