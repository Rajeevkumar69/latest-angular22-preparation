HTTP Client & Signals

Practical example of API integration using Angular HttpClient and Signals.

Concept Overview
HttpClient
HTTP Client

Angular HttpClient is a built-in service used to communicate with backend APIs through HTTP requests such as GET, POST, PUT, PATCH and DELETE.

Signals
Angular Signals

Signals are reactive primitives used to manage application state. When a signal's value changes, Angular automatically updates the dependent UI.

Resource API
Angular Async Data Management

The Resource API in Angular is a built-in, signal-based primitive designed to handle asynchronous data fetching and integrate it directly into Angular's reactive signal ecosystem.

Available Resource API's

Angular provides three main ways to create and manage asynchronous resources, depending on the data source and the type of operation.

01
resource()

General-purpose asynchronous resource using a Promise-based loader.

Promise-based
02
rxResource()
