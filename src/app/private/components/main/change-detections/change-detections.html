Angular Change Detection

Change detection is the process by which Angular check wether any data has changed & update the webpage to display the latest value

Angular provides 2 Change Detection Strategies
01
Eager

Angular Check the component whenever the Change detection traversal reaches it

02
OnPush

Angular Can Skip Cheking The Component when it doesn't need to be checked 

In Angular 22 latest version OnPush is the default change detection Strategies 
But we can still configure the component to use the eager explicitely.
