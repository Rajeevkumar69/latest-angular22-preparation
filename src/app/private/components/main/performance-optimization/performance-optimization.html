Performance Optimization

Performance optimization helps Angular applications run faster, respond smoothly and provide a better user experience.

Why Performance Optimization?

As an application grows, it may contain many components, large amounts of data, API calls, images and complex calculations. Handling these resources inefficiently can make the application slow.

Key Benefits

  • Reduce unnecessary change detection and calculations.
  • Improve initial loading speed.
  • Make user interactions faster.
  • Use CPU and memory efficiently.
  • Build faster, smoother and scalable applications.
Performance Optimization Techniques
  1. Track keyword using @for.
  2. Signals and computed values.
  3. OnPush change detection.
  4. Lazy loading.
  5. @defer block.
  6. Avoid unnecessary computations.
1. @for and Track Keyword

Angular uses the track expression to identify each item in a list. This helps Angular update the required DOM elements instead of recreating the entire list. 

{{ '@for (user of users(); track user.id) {' }}
    {{ '{{ user.name }}' }}
{{ '}' }}
Users List
@for (user of users(); track user.id) {
{{ user.name }} ID: {{ user.id }}
}

Initially John, Bob and Peter are displayed. Clicking Add User inserts Mike at the beginning of the list.

2. Signals and Computed Values

Signals track changes in values and identify which parts of the UI depend on those values. 

count = signal(1);

doubleCount = computed(() => count() * 2);

Count

{{ count() }}

Double Count

{{ doubleCount() }}

Computed signals are lazy and cached. They recalculate when their dependencies change and are read again.

3. OnPush Change Detection

OnPush helps Angular focus on components that need updating instead of checking everything unnecessarily. 

changeDetection: ChangeDetectionStrategy.OnPush

Current Count

{{ count() }}

Angular checks an OnPush component when:

  • It receives a new input value.
  • An event occurs inside the component.
  • A signal used in its template changes.
4. Lazy Loading

Lazy loading loads a component only when the user navigates to its route, reducing the initial JavaScript load.

Before Lazy Loading

{{ '{' }}
    path: 'forms',
    component: AngularFormsComponent
{{ '}' }}

After Lazy Loading

{{ '{' }}
    path: 'forms',
    loadComponent: () => import(
        './pages/angular-forms/angular-forms'
    ).then(c => c.AngularFormsComponent)
{{ '}' }}

We can also use loadChildren to lazy load an entire route configuration.

5. @defer Block

The @defer block delays loading non-critical components until they are needed. 

{{ '@defer (on viewport) {' }}
    <app-child-forms-demo></app-child-forms-demo>
{{ '} @placeholder {' }}
    <p>Scroll down to load Angular Forms</p>
{{ '}' }}

Live Example

@defer (on viewport) { } @placeholder {

Scroll down to load Angular Forms.

} @loading (minimum 500ms) {
Loading...
}

When the placeholder enters the viewport, Angular loads the component and replaces the placeholder with the actual content.

6. Avoiding Unnecessary Computations

Calling a method directly inside a template can cause repeated calculations during change detection. Use computed signals to calculate and cache derived values.

Avoid This Approach

calculateTotal() {{ '{' }}
    return this.products().reduce(
        (sum, product) => sum + product.price, 0
    );
{{ '}' }}

Use Computed Signal

total = computed(() =>
    this.products().reduce(
        (sum, product) => sum + product.price, 0
    )
);
Shopping Cart
@for (product of products(); track product.id) { }
Product Price
{{ product.name }} ₹{{ product.price | number:'1.0-0' }}
Total ₹{{ total() | number:'1.0-0' }}

The initial total is ₹73,000. When the products signal changes, the computed total is recalculated when read again.

7. Performance Profiling

Before applying optimization techniques, identify where the performance problem is occurring.

Slow Page Loading

  • Bundle sizes
  • Route loading
  • Images

Slow Interactions

  • Template expressions
  • Repeated calculations
  • Change detection

Chrome DevTools vs Angular DevTools

Chrome DevTools Angular DevTools
HTML and CSS inspection Component tree
JavaScript debugging Component properties
Network activity Change detection profiler
Overall performance Injector and router trees

How to use Angular DevTools?

  1. Install Angular DevTools from Chrome Web Store.
  2. Run the application using ng serve.
  3. Open browser DevTools and select the Angular tab.
  4. Use Components to inspect the component tree.
  5. Use Profiler to analyze change detection cycles.
  6. Explore Injector Tree and Router Tree.
Conclusion

Performance optimization is about identifying performance problems and choosing the right solution. These techniques reduce unnecessary work, load resources efficiently and make Angular applications faster and smoother.
