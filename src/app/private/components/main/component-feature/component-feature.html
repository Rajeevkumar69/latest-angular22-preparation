01

What is a Component?

Introduction to Angular components

Components are the fundamental building blocks of an Angular application. Each component controls a specific part of the UI and consists of a TypeScript class, HTML template and styles.

Angular Component UI Building Block

02

Creating Components

Generate components using Angular CLI

Angular CLI provides commands to generate new components.

Terminal Angular CLI 
ng generate component components/header
ng g c components/footer
Tip: Both commands perform the same operation. ng g c is the shorthand syntax.

@Component Decorator

Configure component metadata

The @Component decorator provides metadata that tells Angular how to create and use a component.

header.ts TypeScript 
import {{ '{' }} Component {{ '}' }} from '@angular/core';

@Component({{ '{' }}
  selector: 'app-header',
  standalone: true,
  imports: [],
  templateUrl: './header.html',
  styleUrl: './header.css'
{{ '}' }})
export class HeaderComponent {{ '{' }}

{{ '}' }}
selector HTML tag used to render the component.
standalone Defines standalone component configuration.
imports Dependencies required by the component template.
templateUrl External HTML template file.
styleUrl External component stylesheet.

Standalone Components

Understanding standalone architecture

Standalone components can directly declare their template dependencies through the imports array without requiring an NgModule declaration.

dashboard.ts TypeScript 
import {{ '{' }} Component {{ '}' }} from '@angular/core';
import {{ '{' }} HeaderComponent {{ '}' }} from '../header/header';
import {{ '{' }} FooterComponent {{ '}' }} from '../footer/footer';

@Component({{ '{' }}
  selector: 'app-dashboard',
  standalone: true,
  imports: [
    HeaderComponent,
    FooterComponent
  ],
  templateUrl: './dashboard.html'
{{ '}' }})
export class DashboardComponent {{ '{' }}

{{ '}' }}
Important: Standalone components manage their own template dependencies through the imports array.

Rendering Components

Using component selectors in HTML

To render a component inside another component, use its selector as an HTML element.

App Component Parent Component
Header Component app-header
Footer Component app-footer
app.ts TypeScript 
import {{ '{' }} Component {{ '}' }} from '@angular/core';
import {{ '{' }} HeaderComponent {{ '}' }} from './components/header/header';
import {{ '{' }} FooterComponent {{ '}' }} from './components/footer/footer';

@Component({{ '{' }}
  selector: 'app-root',
  standalone: true,
  imports: [
    HeaderComponent,
    FooterComponent
  ],
  templateUrl: './app.html'
{{ '}' }})
export class AppComponent {{ '{' }}

{{ '}' }}
app.html HTML 
<app-header></app-header>

<main>
  <h2>Welcome to Angular 22</h2>
</main>

<app-footer></app-footer>
Remember: Import the child component class into the parent's imports array before using its selector.
