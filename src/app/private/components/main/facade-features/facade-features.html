Facade Pattern

Angular Architecture · Design Patterns

What is a Facade?

A facade provides a simplified Interface. It hides Implementation details from components. Components dont need to know where data comes from.

It acts as a single entry point between the UI layer and underlying services.
How Facade Works
Architecture
Component (UI)
Handles user interactions
Facade Service
Centralized state & business logic
API Service
HTTP requests
Other Services
Data & operations
Advantages
Deploying
Helps isolate implementation changes and integration concerns.
Cleaner Component
Keeps components focused on UI and user interactions.
Easier Refactoring
Underlying service changes can be isolated behind the facade.
Centralized Business Logic
Keeps business operations in a centralized layer.
Core Concept

A facade iss an bastraction layer that sits between components & underlying services. Providing a simplified & decoupled API for the UI layer.
