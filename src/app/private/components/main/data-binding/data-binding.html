Angular Data Binding

Learn how data moves between the component and the HTML template.

1. Interpolation

Interpolation is used to display component data in HTML using double curly braces {{ '{{ }}' }}.

Product Name Product Number Product Price
{{productName}} {{productNumber}} {{productPrice}}
2. Property Binding

Property Binding is used to pass component data to HTML element properties using square brackets [ ].

3. Event Binding

Event Binding is used to call component methods when an event occurs in HTML using parentheses ( ).

Move mouse over the circle
4. Two-Way Data Binding

Two-Way Data Binding is used to synchronize data between the component and HTML. Changes in either place are reflected in the other using [(ngModel)].
