Parent and Child Component Communication

Angular Signal APIs

Three ways to communicate between Parent and Child Components.

input()
Parent → Child

Used to receive data from the parent component. The child can read the value but cannot directly modify the input signal.

input.required<string>()
Property Binding: [property]
output()
Child → Parent

Used to emit events or send data from the child component to the parent component using emit().

output<string>()
Event Binding: (event)
model()
Two-way

Used to receive and update a value between parent and child components. Supports set() and update().

model(1)
Two-way Binding: [(property)]
