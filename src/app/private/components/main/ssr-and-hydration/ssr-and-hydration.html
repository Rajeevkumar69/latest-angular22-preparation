SSR & Hydration

Angular 22 | Server Rendering & Client Hydration

What is SSR?

SSR (Server-Side Rendering) allows Angular to generate the initial HTML on the server and send it to the browser, so users can see the page content earlier.

Server generates HTML Browser displays content
What is Hydration?

Hydration allows Angular to reuse the HTML generated by the server and connect it with the application's functionality, including event listeners, to make the page interactive.

Reuses existing DOM Attaches functionality

Advantages of SSR
Better SEO

Search engines can receive meaningful HTML content.

Faster Content Visibility

Users can see initial content without waiting for full client rendering.

Improved Initial Experience

Important page content can appear earlier.

Social Sharing

Social crawlers can access page metadata and content.

Advantages of Hydration
DOM Reusability

Reuses existing server-rendered DOM instead of recreating it.

Less UI Flickering

Prevents unnecessary DOM destruction and recreation.

Better Performance

Reduces unnecessary rendering work and can improve Core Web Vitals.

Event Handling

Connects event listeners to make server-rendered content interactive.

Important Hydration Features
Event Replay

Captures user events that happen before hydration completes and replays them after hydration, so early interactions are not lost.

Incremental Hydration

Hydrates specific parts of an application only when required, instead of making the entire application interactive at once. It works with Angular's @defer blocks.

DOM Reuse

Angular matches the existing server-generated DOM with its client-side structure and reuses the existing elements.

When to Use?
SSR

E-commerce websites, blogs, news websites, product pages and SEO-focused applications.

Hydration

Applications that use SSR or prerendering and need to reuse server-rendered HTML while adding client-side interactivity.

Key Takeaway

SSR generates HTML on the server for faster initial content visibility, whereas Hydration reuses that HTML and connects Angular functionality to make the application interactive.
