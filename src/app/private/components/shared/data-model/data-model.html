Angular model() Signal

What is model() Signal?

Angular's model() creates a writable signal that supports two-way data binding between parent and child components.

How It Works

The parent passes a signal to the child using [(propertyName)]. Both components can update the value, and changes are automatically synchronized.

Real-World Example

Modal visibility: Parent opens the modal by setting isOpen to true. Child closes it by setting isOpen to false. Both components reflect the updated state automatically.

Syntax

Child: isOpen = model(false);
Parent: [(isOpen)]="isModalOpen"

When to Use

Use model() for reusable components such as modals, pagination, toggle switches, sliders and dropdowns where both parent and child need to update the same value.
